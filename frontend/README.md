# Frontend

React + Vite + TypeScript frontend for the portfolio interface.

## Principles

- Lightweight UI (no Tailwind for now).
- Consume backend-only public endpoints.
- Never expose secrets in client bundle.

## Main Pages

- Home: profile, metrics, project feed.
- Project detail: release notes, changelog, live links.

## Run

```bash
pnpm install
pnpm dev
```

Default address: `http://localhost:3000` (SSR server).
